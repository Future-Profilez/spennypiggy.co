# Spennypiggy.co

## Installation
..* Clone the repo

..* Install Composer Packages

```shell
composer install
```

..* Install NPM Packages

```shell
npm install
```

..* Connect the database and run migration


```shell
php artisan migrate
```

..* Run Project

... Start PHP Server

```shell
php artisan serve
```
... Start NPM Server

```shell
npm run dev
```
