## Asynchronous Processing Flow

```
    ┌─────────────────────────────────────────────────────────────────────────────────┐
    │                           BACKGROUND JOB PROCESSING                             │
    └─────────────────────────────────────────────────────────────────────────────────┘
                                            │

                                            │                                         │
    Controller Dispatches Job ──────────────┼───────────────────────────────────────┐ │
                                            │                                       │ │
    Job Added to Redis Queue ───────────────┼─────────────────────────────────────┐ │ │
                                            │                                     │ │ │
    ┌─────────────────────────────────────────────────────────────────────┐     │ │ │ │
    │                     QUEUE WORKERS                                  │     │ │ │ │
    │                                                                     │     │ │ │ │

    │  │   Email     │  │   Payment   │  │   Social    │  │   Content   ││     │ │ │ │
    │  │  Worker     │  │   Worker    │  │   Worker    │  │   Worker    ││     │ │ │ │
    │  └─────────────┘  └─────────────┘  └─────────────┘  └─────────────┘│     │ │ │ │
    └─────────────────────────────────────────────────────────────────────┘     │ │ │ │
                                            │                                   │ │ │ │
    Job Processed by Worker ────────────────┼─────────────────────────────────┐ │ │ │ │

                                            │                               │ │ │ │ │ │
```
